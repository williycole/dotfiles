# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Config policy

Before hand-writing an override in `lua/plugins/`, check whether a LazyVim
extra or default already does it (`:LazyExtras`, or grep the LazyVim source).
Prefer enabling an extra over re-skinning a default — keep the custom layer thin.
